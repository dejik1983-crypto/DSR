# Как внести вклад
Спасибо за интерес к DSR. Перед отправкой изменений:

1. Создайте отдельную ветку для изменения.
2. Старайтесь сохранять исходные FB2: результат обработки должен записываться в отдельный файл.
3. Не добавляйте в коммиты личные книги, модели RUAccent, Python-окружения, кэш, каталоги `bin`, `obj` и `publish`.
4. Для изменений обработки FB2 проверьте сохранение структуры, разметки, ссылок и встроенных иллюстраций, а также повторное открытие результата парсером DeepReader.
5. Соберите проект командой `dotnet build FB2AccentConverter.csproj -c Debug -p:EnableWindowsTargeting=true` из папки DSR.
6. В описании Pull Request укажите, что изменилось и как проверялось.

DSR ссылается на соседний проект DeepReader 1.6.2. Если у вас другая структура каталогов, путь при сборке можно передать через `-p:DeepReaderProjectPath="путь\DeepReader.csproj"`.
