# DSR — FB2 Accent Converter
[![Версия](https://img.shields.io/badge/version-1.0.0Beta-blue)](https://github.com/dejik1983-crypto/DSR/releases)

**Версия: 1.0.0Beta** · [История изменений](CHANGELOG.md) · [Лицензия MIT](LICENSE)

DSR создаёт копии FB2-книг с автоматически расставленными русскими ударениями. Ударения записываются комбинируемым символом `U+0301`, который распознаёт и корректно отображает [DeepReader](https://github.com/dejik1983-crypto/DeepReader).

> Автоматическая расстановка может ошибаться, особенно на омографах, стихах и специальных текстах. Проверяйте результат перед использованием. DSR по умолчанию сохраняет отдельную копию и не изменяет исходную книгу.

Для разбора и проверки FB2 используется `Fb2Parser` из проекта DeepReader 1.6.2. DSR и DeepReader остаются отдельными проектами; DSR ссылается на DeepReader относительным путём `../DeepReader_x64 V1.6.2Beta Bionic/DeepReader.csproj`. После обработки результат проверяется тем же парсером. Преобразуются текстовые узлы XML, а встроенные изображения не передаются языковой модели.

**Сторонние компоненты:** расстановка ударений выполняется библиотекой [RUAccent](https://github.com/Den4ikAI/ruaccent), которая имеет собственную лицензию и зависимости. Их условия распространяются независимо от лицензии DSR; перед распространением готовой сборки ознакомьтесь с ними.

## Возможности
- Обработка всей книги или выбранных глав.
- Выбор модели RUAccent и устройства CPU/CUDA.
- Сохранение результата в отдельный FB2-файл; исходная книга не перезаписывается.
- Сохранение иллюстраций либо их исключение из выходной копии.
- CLI для пакетной обработки.
- Проверка результата парсером DeepReader.

## Требования
- Windows x64.
- Python 3.10+ и зависимости из `requirements.txt`.
- При первом запуске выбранная RUAccent-модель скачивается из интернета.
- Для сборки из исходников нужны .NET 8 SDK и проект DeepReader 1.6.2 в соседней папке (см. ниже).

## Сборка и установка
Чтобы собрать приложение из исходников, необходимы Windows и .NET 8 SDK. Ожидаемая структура каталогов: папка `DSR/` рядом с `DeepReader_x64 V1.6.2Beta Bionic/`. По умолчанию DSR ссылается на проект DeepReader 1.6.2 относительно собственного `.csproj`; если проекты расположены иначе, путь можно переопределить параметром MSBuild `-p:DeepReaderProjectPath="путь\DeepReader.csproj"`.

Для публикации приложения выполните из папки DSR:

```powershell
.\publish.bat
```

Каталог `publish` содержит готовое приложение Windows x64 со встроенным .NET runtime и компонентами DeepReader. На целевом компьютере нужен 64-разрядный Python 3.10 или новее. Один раз запустите `setup-python.bat` из `publish`, чтобы установить Python-зависимости RUAccent, затем запускайте `FB2AccentConverter.exe`. При первой конвертации модель скачивается из интернета. Можно указать путь к Python переменной среды `PYTHON`.

Для ручной установки Python-зависимостей из папки с `requirements.txt`:

```powershell
python -m pip install -r requirements.txt
```

## Использование
### Графический интерфейс
Запустите `FB2AccentConverter.exe` без аргументов — откроется графический интерфейс:

1. Выберите FB2-книгу. Программа прочитает оглавление настоящим парсером DeepReader.
2. Проверьте путь результата. По умолчанию рядом с исходником создаётся `Имя_ударения.fb2`; путь и имя можно изменить.
3. Выберите обработку всей книги или только глав. В списке глав используйте клик, `Ctrl+клик` для отдельных глав и `Shift+клик` для диапазона.
4. Оставьте включённой галочку сохранения иллюстраций, если изображения должны остаться в копии.
5. При необходимости выберите модель и устройство (`CPU` — рекомендуемый универсальный вариант; `CUDA` требует совместимой настройки GPU), затем нажмите «Начать конвертацию».

Кнопка «Очистить модели и кэш» удаляет только `model-cache` рядом с программой. Она не трогает исполняемый файл, скрипт, Python, исходные книги или результаты; после очистки модели при следующем запуске будут скачаны повторно. Кэш ограничен папкой программы, чтобы не разрастались пользовательские глобальные кэши.

### Командная строка
Для пакетной обработки и автоматизации доступен CLI. Полный список параметров: `FB2AccentConverter.exe --help`.

```powershell
.\FB2AccentConverter.exe "D:\Books\Книга.fb2" --model turbo3.1 --device CPU
```

Для пакетного режима можно передать папку; для рекурсивного обхода добавьте `--recursive`. При ошибке временный файл результата удаляется, исходник остаётся нетронутым.

## Сборка из исходников
Для сборки из исходников клонируйте DSR и [DeepReader](https://github.com/dejik1983-crypto/DeepReader) рядом друг с другом, сохранив каталог DeepReader с версией 1.6.2:

```text
<workspace>/
├── DSR/
└── DeepReader_x64 V1.6.2Beta Bionic/
```

Соберите релизную версию из папки DSR:

```powershell
.\publish.bat
```

Путь к проекту DeepReader можно переопределить параметром MSBuild `-p:DeepReaderProjectPath="путь\DeepReader.csproj"`. Скрипты `publish.bat` и `install.bat` публикуют приложение в `DSR/publish/`; `install.bat` предварительно устанавливает зависимости Python.

## RUAccent
Используется библиотека [RUAccent](https://github.com/Den4ikAI/ruaccent). Символ `+` перед ударной гласной в ответе модели преобразуется в комбинируемое ударение `U+0301`, поддерживаемое DeepReader. Результаты модели могут быть неточными — всегда проверяйте обработанный текст.
