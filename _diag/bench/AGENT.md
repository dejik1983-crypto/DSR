# Бенчмарк DSR: как мерить точность ударений (Этап 1)

Задача этого каталога — **измерить**, а не улучшить. Любое «стало лучше» без цифр
из этого каталога — самоуспокоение: у нас уже был случай, когда модели по отдельным
словам «всё правильно», а во фразе ошибка у всех трёх.

Эталон (`gold/`) в архив не вкладывается по требованию владельца и не должен
уходить в коммит: это разметка книги и ручная работа.

## Что уже измерено (сессия 2026-10-31)

Тихий Дон, 191 004 предложения, 427 901 слово. Подробно — `reproduce.md`.

| | слов со знаком | доля |
|---|---|---|
| база (add-stress) | 263 050 | 61.5 % |
| RUAccent по базе | 318 109 | 74.3 % |
| Silero по базе | 284 431 | 66.5 % |
| итог | 280 379 | 65.5 % |

- **Ни один файл не размечает книгу целиком.** Самая «говорливая», RUAccent,
  оставляет без знака 26 % слов. «99.7 %» модели — про её ответ там, где её
  спросили, а не про покрытие книги.
- **Все четыре файла согласны на 83.6 % слов**, но почти треть этого согласия —
  согласие молчания (106 320 слов без знака у всех).
- Модели расходятся в основном там, где одна молчит: Silero не ставит знак у
  ~38 тысяч слов, которые RUAccent размечает. Это разные политики, а не разные
  ударения.
- Итог расходится с обеими моделями в ~17 тысячах мест.
- Наша фраза: во всех трёх движках одна и та же ошибка. Вывод: **ошибка не в
  выборе движка**, а в том, что слово решается без фазы предложения.

## Правила, без которых бенчмарк врёт

1. Файл прогона и эталон сравниваются **по предложениям**, найденным по тексту,
   а не по номеру: любая правка разрезки сдвигает нумерацию.
2. Слова — по правилу `Program.WordTokens` (знак ударения — часть слова, дефис —
   разделитель). Иначе число слов в файлах не сходится.
3. Знак ударения — U+0301 **после** гласной. Номер гласной считается с 0 в коде,
   для человека печатается с 1.
4. Ошибка «внутри идиомы» поднимается в свой класс — в общем «ударении» её не видно.
5. Эталон из «итога» — **черновик**. Человек подтверждает каждое предложение.

   по позициям (Этап 4), а omogre — как арбитра (Этап 5).

## Чего здесь нет специально

Автоматического эталона. Любой «эталон из модели» делает замер бессмысленным:
он проверяет модель модели. Черновик — только ускоритель ручной работы.
