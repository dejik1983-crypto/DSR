# Демонстрационные FB2-файлы
В этом каталоге находятся небольшие тестовые примеры, не содержащие исходные книги пользователя:

- `DeepReader-accented-sample.fb2` — пример FB2 с уже расставленными ударениями для проверки отображения.
- `DeepReader-accented-sample_ударения.fb2` — результат конвертации, оставленный для сопоставления.

Не помещайте сюда полные книги или материалы, на распространение которых у вас нет прав.
